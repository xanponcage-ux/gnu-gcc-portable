# LDP Tableau V8 — implementation status and data contract (2026-11-20)

Source: "Overall LDP Summary Dashboard (1).docx" (3 pages), plus LDPIS/Tableau query.txt. V8 is a non-destructive **layout draft**, not a completed production dashboard. It retains V7 and adds dashboard "LDP Three Section Tables - DRAFT" with existing native Tableau worksheets, replacing bar-chart emphasis with tables. Existing sheets are reused without altering their underlying measures. The right column currently contains temporary stock tables, NOT the specified production/sign-off section.

## Exact source requirement
- Left block: MES Order Progress. Top KPIs BOP, BOF, Pending DO, total linked order stock. Vertical and zone tables with BOP and BOF. Pending DO must come from SAP ZBSOSTATUS: all DO/STO minus dispatched, at order grain.
- Middle block: MES V_LDP_PRODN joined to order book for linked stock, broken down by vertical and zone, plus unlinked stock table by vertical. Age categories for both linked and unlinked batches come from SAP YSTOCKN for plant 780. Include total stock, total linked stock, total unlinked stock, hold batch MT and percentage.
- Right block: production/sign-off metrics by vertical and zone, as pictured on page 3 of source document. **Do not enable until order-wise sign-off is captured in MES.** Do not substitute stock quantities for these fields.
- Single page, three horizontal blocks left to right, with readable tabular values and grand totals; charts are optional extras, not substitutes.

## Data quality / outstanding dependencies
1. SQL in Tableau query.txt hardcodes PENDING_DO=0; also GRNCOMP_QTY, GRNCOMP_PER, ROLLING_OSP, ROLLING_MTD, ROLLCOMP_PER, PRODUCTION_OSP, PRODUCTION_MTD and PRODUCTION_PER as zero. These are placeholders, not actual data.
2. SQL computes TOTAL_UNLINK_STK using non-null customer order ID with LOM_CD_STATUS='WF'; the business definition of unlinked must be verified before using it as a validated KPI.
3. SQL's segment/zone subquery S reads all V_LDP_ORDER_PROG without applying M's order status, creation date and EPA restrictions. Its totals may differ from M; align grains/filters before publishing.
4. Stock-age distribution from YSTOCKN and production sign-off detail are not provided by the SQL file.
5. Oracle service endpoint from user: 132.145.99.84:1521/ldpisprd. No credentials are stored here. Live connectivity has not been tested.
6. V8 was generated by XML transformation of the V7 workbook. Tableau Desktop 2022.4 rendering/open validation is pending. Do not treat it as certified.
